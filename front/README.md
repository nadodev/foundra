# Startup Journey — Protótipo HTML Completo

Protótipo estático completo do ecossistema Startup Journey.

## Como navegar

Abra `all-pages.html` para acessar o índice de todas as telas.

## Áreas incluídas

- Páginas públicas e autenticação
- Área do Empreendedor
- Área do Programa
- Área do Mentor
- Visão conceitual para investidores

## Fluxo principal do empreendedor

Landing page → Cadastro → Seleção de perfil → Onboarding → Criar startup →
Análise inicial → Visão Geral → Jornada → Validação → Pesquisa → Evidências →
Entrevistas → Concorrentes → Business Model → MVP → Pitch →
Maturidade da Startup → Passaporte da Startup

## Observações

- HTML/CSS/JS puro.
- Sem backend.
- Ações são simuladas.
- Interface predominantemente em português.
- Termos muito comuns no ecossistema, como Business Model, MVP, Pitch e Lean Canvas, foram mantidos.
- Conceito principal: Hipótese → Teste → Evidência → Decisão.
